## 0. 문서 상태

- 문서 버전: v1.0
- 작성 기준: 현재 코드 + 제품 방향 확정 반영
- 목적: 현재 기능을 구조적으로 분류하고 상태/우선순위/책임 + 제품 방향을 명확히 함

---

## 1. 기능 상태 정의

본 문서에서 기능 상태는 아래 4종으로 구분한다.

- **운영중**: 현재 코드상 제공되고 있으며 주요 흐름에서 사용됨
- **부분구현**: 일부 구현은 되어 있으나 기능 완성도/일관성 부족
- **미구현**: 아이디어는 있으나 현재 코드상 핵심 구현 없음
- **보류**: 추후 검토 대상으로 현재 우선순위에서 제외

---

## 2. 우선순위 정의

- **P0**: 서비스 핵심. 없으면 제품 의미가 약해짐
- **P1**: 신뢰도/운영 안정성 강화
- **P2**: 사용성/확장성 고도화
- **P3**: 장기 확장

---

## 3. 기능 분류 체계

- D: 데이터
- I: 지표(Indicators)
- M: 모델(Model)
- S: 신호(Signal)
- O: 운영(Operation)
- U: UI/UX

## D-001. 원천 시세 수집

- 분류: 데이터
- 우선순위: P0
- 상태: 운영중

### 목적
거래소에서 OHLCV 데이터를 수집하여 시스템의 가장 기초 데이터를 제공한다.

### 설명
Binance 기준 시세 데이터를 수집하고 DB에 저장한다.

### 입력
- exchange (현재 Binance 고정)
- symbol (현재 ETH 고정)
- timeframe

### 출력
- raw OHLCV 데이터

### 저장 위치
- `raw.eth_ohlcv`

### 관련 배치/구현
- ingestion pipeline
- Airflow ingestion DAG

### 화면 노출
- 직접 노출 없음
- 차트 및 후속 기능의 기반 데이터

### 오너 확인 사항
- [x] 거래소 Binance 고정
- [x] ETH 단일 전략 유지
- [ ] 백필 정책 강화 필요

## D-002. 가격 히스토리 조회

- 분류: 데이터
- 우선순위: P0
- 상태: 운영중

### 목적
차트 및 과거 분석을 위해 캔들 데이터를 범위 기반으로 조회한다.

### 설명
사용자는 start/end/before/limit 조건으로 과거 캔들 데이터를 조회할 수 있다.

### 입력
- start
- end
- before
- limit
- timezone
- exchange (고정)
- symbol (ETH)
- timeframe

### 출력
- 시계열 OHLCV 목록

### 관련 API
- `GET /prices/history`

### 화면 노출
- 메인 차트 (보조 UI)

### 오너 수정 포인트
- [ ] 최대 조회량 정책
- [ ] 무한 스크롤 여부
- [ ] 타임프레임 범위 (15m/1h/4h 중심)
