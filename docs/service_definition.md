## 2. 한 줄 설명

본 서비스는 Binance 기반 ETH/USDT 시장 데이터를 수집하고, 기술지표 및 머신러닝 기반 예측을 조합하여  
👉 **사용자의 매매 판단을 지원하는 시그널 서비스이며, 대시보드는 이를 확인하기 위한 보조 인터페이스이다.**

---

## 3. 서비스 배경

본 프로젝트는 초기에는 실험적 성격으로 다양한 기능을 빠르게 추가하면서 확장되었다.  
그 과정에서 기능은 많아졌지만 서비스 정의, 범위, 우선순위, 요구사항, 화면 구성 원칙 등이 명확히 정리되지 않았다.

그 결과 다음과 같은 문제가 발생했다.

- 현재 서비스가 정확히 무엇인지 한 문장으로 설명하기 어렵다.
- 구현된 기능과 문서상 기능이 일치하지 않는다.
- 제품 범위가 “분석 도구”인지 “실제 트레이딩 플랫폼”인지 모호하다.
- 기능 추가 시 우선순위 판단 기준이 없다.
- 향후 리팩터링/확장/삭제 판단이 어려워진다.

본 문서는 이 문제를 해결하기 위해 현재 코드 기준으로 서비스 정체성을 재정의하기 위해 작성한다.

---

## 4. 서비스 목적

본 서비스의 목적은 사용자가 ETH/USDT 시장 데이터를 기반으로  
👉 **실제 매매 행동(진입/관망/청산)을 더 쉽게 결정할 수 있도록 지원하는 것**이다.

이를 위해 다음을 제공한다.

1. 현재 시장 상태를 빠르게 파악한다.
2. 기술지표와 ML 예측 결과를 함께 확인한다.
3. **다단계 시그널 기반 매매 방향을 제공한다.**
4. TP/SL 및 포지션 사이즈 등 실행 수준의 정보를 제공한다.
5. 신호의 신뢰도와 과거 성과를 검토한다.
6. 데이터/모델/운영 상태를 확인한다.

단, 모든 정보는 언제든지 사용자가 직접 확인할 수 있도록 제공한다.

- 향후 구독형 시그널 서비스 잠재 고객

---

### 5.3 현재 비대상

## 6. 핵심 제공 가치

본 서비스는 사용자에게 아래 가치를 제공한다.

### 6.1 행동 중심 의사결정 지원
단순 정보 제공이 아니라  
👉 **매매 행동을 직접 지원하는 시그널을 제공한다.**

---

### 6.2 시장 상황 통합 확인
가격, 거래량, 기술지표, 예측 결과, 신호를 하나의 대시보드에서 확인할 수 있다.

---

### 6.3 설명 가능한 신호
신호는 단순 결과가 아니라  
👉 지표, ML, MTF, 리스크 기반 근거와 함께 제공된다.

---

### 6.4 신뢰도 검토
정확도뿐 아니라  
👉 **수익률 기반 성과까지 검토 가능하다.**

---

### 6.5 운영 가시성
데이터 수집, 모델 상태, 파이프라인 상태를 확인할 수 있다.

---

## 7. 서비스 범위

### 7.1 현재 포함 범위
- Binance 기반 시세 데이터 수집
- 15분 봉 OHLCV 저장
- 기술지표 계산 및 저장
- ML 분류/회귀 기반 예측
- 앙상블 신호 생성
- **다단계 시그널 생성 (6단계)**
- TP/SL 및 포지션 사이즈 계산
- 신호 이력 조회
- 예측 정확도 및 성과 추적
- 모델 학습 수동 트리거 및 상태 확인
- 운영 상태 확인
- 대시보드 UI 제공

---

### 7.2 현재 제외 범위
- 실제 주문 실행
- 포지션 체결/정산
- 사용자 인증/권한
- 결제/구독
- 멀티유저 협업
- 다중 거래소 통합 운영
- 자동매매 봇 배포/관리

## 9. 핵심 사용자 시나리오

### 시나리오 A. 현재 신호 확인
사용자는 대시보드에 접속한다.  
👉 **현재 시그널 / 확률 / TP/SL / 포지션 사이즈**를 확인한다.  
이를 바탕으로 진입 여부를 결정한다.

---

### 시나리오 B. 과거 신뢰도 검토
사용자는 최근 신호 이력과  
👉 **정확도 + 수익률 성과**를 확인한다.

---

### 시나리오 C. 모델 재학습
운영자는 학습 패널에서 ML 학습을 실행한다.  
진행률, 로그, 학습 완료 여부를 확인한다.

---

### 시나리오 D. 데이터 이상 점검
운영자는 데이터 상태 패널을 보고  
수집 지연, 피처 지연, 모델 상태 등을 점검한다.
